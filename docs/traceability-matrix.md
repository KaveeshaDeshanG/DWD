**2026-09-02 continuation-session note**: Phase 7's code, tests, and a UI-polish pass all existed uncommitted in the working tree (never committed — baseline was still Phase 6's `0682ae6`) when this session began, and this table's Phase 7 rows described them as fully verified. Final state, all real: `dotnet build` 0 errors/0 warnings; `dotnet test` 32/32 passed across 3 consecutive runs; full HTTP sweep (browsing, Guest-restricted search, Member full search with availability annotation, booking creation, overlap rejection, ownership isolation with a second real member, unauthenticated redirects, 404 pages) all passed against the real running app and real database; DB integrity confirmed unchanged (8 tables, 20 constraints).
